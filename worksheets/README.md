# ใบงาน: K-Means และ Neural Network กับข้อมูลฝึก / ทดสอบ

ไฟล์ประกอบใบงานที่ให้นักศึกษาต่อบล็อกใน ThaiPyBlocks เพื่อแบ่งข้อมูลเป็นชุดฝึก (train) กับชุดทดสอบ (test)
ให้โมเดลเรียนจากชุดฝึก แล้วตรวจกับข้อมูลที่โมเดลไม่เคยเห็น ข้อมูลทั้งสองชุดเป็นข้อมูลสมมติที่สร้างขึ้นเพื่อการสอน

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `mall_customers.csv` | กิจกรรมที่ 1 K-Means: ลูกค้าห้าง 200 คน (customer_id, gender, age, income พันบาท/เดือน, spending 1–99) มี 5 กลุ่มตาม income กับ spending |
| `seed_germination.csv` | กิจกรรมที่ 2 Neural Network: ถาดเพาะ 400 ถาด (temperature °C, humidity %, germinated งอก/ไม่งอก) ถาดงอกรวมเป็นวงรีที่เส้นตรงแบ่งไม่ได้ |
| `solution_kmeans.json` | เฉลยบล็อกกิจกรรมที่ 1 |
| `solution_neural_network.json` | เฉลยบล็อกกิจกรรมที่ 2 |
| `make_worksheet_data.py` | สร้างไฟล์ CSV ทั้งสองซ้ำ (ค่าสุ่มคงที่ ได้ไฟล์เดิมทุกครั้ง ต้องมี numpy) |
| `worksheet1_kmeans.pdf` | ใบงานที่ 1 สำหรับพิมพ์แจก (A4 6 หน้า): จุดประสงค์ ข้อมูล ขั้นตอนพร้อมภาพบล็อกทีละตอน ตารางบันทึกผล 4 ตาราง คำถาม 4 ข้อ |
| `worksheet2_neural_network.pdf` | ใบงานที่ 2 สำหรับพิมพ์แจก (A4 5 หน้า): ขั้นตอน 5 ตอน ตารางบันทึกผล 2 ตาราง คำถาม 6 ข้อ |
| `answer_key.pdf` | เฉลยสำหรับผู้สอน (A4 5 หน้า): ค่าที่ควรได้ทุกตาราง กราฟที่ควรเห็น และแนวคำตอบ |
| `worksheets_all.pdf` | ใบงานที่ 1 + ใบงานที่ 2 + เฉลย รวมในไฟล์เดียว (16 หน้า มีบุ๊กมาร์กแต่ละส่วน) |
| `make_worksheet_pdf.py` | สร้าง PDF ทั้งหมดใหม่: ถ่ายภาพบล็อกจากเฉลยในแอปทีละตอน แล้วพิมพ์หน้าด้วย Chromium และฟอนต์ของแอป (ต้อง build, npm ci ใน vendor/ และ pip install playwright pypdf pillow) |

## ใช้กับแอป

1. กด "ข้อมูลของฉัน" → "เลือกไฟล์" แล้วอัปโหลดไฟล์ CSV ของกิจกรรม
2. นักศึกษาต่อบล็อกเองตามใบงาน · ผู้สอนเปิดเฉลยได้ที่เมนู ⋯ → เปิดโครงงาน → เลือกไฟล์ `solution_….json` แล้วกด ▶ รัน
3. กดปุ่ม PDF ในแท็บผลลัพธ์เพื่อเก็บผลส่งงาน

ใบงานฉบับพิมพ์คือ `worksheet1_kmeans.pdf` และ `worksheet2_neural_network.pdf` (ไม่มีเฉลย) ถ้าแก้เนื้อหา ให้แก้ข้อความใน ws1() / ws2() ของ make_worksheet_pdf.py แล้วรัน `python3 worksheets/make_worksheet_pdf.py`

## ผลที่ควรได้ (ค่าเริ่มต้นของเฉลย)

- K-Means (test_size 0.2, random_state 42): ชุดฝึก 160 / ทดสอบ 40 คน · ข้อศอกของกราฟ elbow ที่ k = 5
  · Silhouette ชุดฝึก 0.704 ชุดทดสอบ 0.651 · ลูกค้าใหม่ รายได้ 30 คะแนนใช้จ่าย 85 อยู่กลุ่ม 4 (รายได้น้อย ใช้จ่ายสูง)
- Neural Network (test_size 0.25 แบบ stratify, random_state 42, StandardScaler): LogisticRegression ชุดฝึก 0.450 ชุดทดสอบ 0.460
  · MLPClassifier (16,) max_iter 1000 ชุดฝึก 0.963 ชุดทดสอบ 0.940 · การทาย "ไม่งอก" ทุกถาดได้ 0.59

ค่าทั้งหมดตรงกับโค้ด Python ที่แอปสร้างเมื่อรันด้วย pandas 3.0 และ scikit-learn 1.8 จริง
`python3 test/worksheet_test.py` ตรวจเฉลยทั้งสองและการทดลองตามใบงานอีก 11 แบบ (เปลี่ยน k, random_state, test_size, จำนวนนิวรอน, max_iter, ปิดการปรับสเกล)
